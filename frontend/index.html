Secure data sharing

Send your passwords, payment cards, secure notes or other private data with a secure link. 2FAS Share lets you share sensitive information end-to-end encrypted, with no account required, fully private and free to use.

Customize the security with optional password protection, automatic link expiration and one-time access. Built on open-source code and a zero-knowledge architecture, 2FAS Share never has access to the data you share.

2FAS Share is a JavaScript-powered application. To create or open a secure link, please enable JavaScript in your browser.

  • No accounts
  • Free and easy to use
  • Private

How does it work?

  1. Create a message

    Add the passwords, notes, or private data you want to share.

  2. Customize the security

    Increase the security of the shared data.

  3. Set up a safe password

    This ensures that only trusted people can access the data inside.

  4. Share the data

    Generate the link with the data inside and send it to others.
